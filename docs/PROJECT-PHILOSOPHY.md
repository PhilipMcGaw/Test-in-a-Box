# Project Philosophy

Test in a Box is an engineering validation platform.

Its purpose is to make laboratory tests repeatable, traceable, maintainable
and easier to extend.

## Priorities

1. Reliability
2. Traceability
3. Repeatability
4. Simplicity
5. Extensibility

## Principles

- Treat bench-tested and merely implemented drivers differently.
- Document observed behaviour rather than assumptions.
- Preserve the software, configuration, procedure and instrument identity
  used for every run.
- Keep installation and deployment reproducible.
- Prefer clear engineering workflows over unnecessary abstraction.
- Keep Blockly focused on using instruments; keep Engineering Tools focused
  on developing and commissioning instrument support.
