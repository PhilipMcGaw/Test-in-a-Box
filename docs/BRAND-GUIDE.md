# Test in a Box Brand Guide

Version: v0.1.0-alpha

## Purpose

This guide defines the visual identity used throughout Test in a Box
documentation, diagrams, screenshots and the web application.

The goal is a clean engineering-documentation style rather than a
marketing brochure.

## Master Logo

The file:

    docs/images/test-in-a-box.png

is the single source of truth for the project logo.

Do not redraw, reinterpret or replace it with AI-generated artwork.

Use this exact asset in:

- README
- Documentation
- Architecture diagrams
- Workflow diagrams
- Presentations
- Web application

## Colour Palette

Primary:
- Navy (from the cube outline)

Accent:
- Green (from the check mark)

Background:
- White

Secondary text:
- Dark slate grey

Status colours:
- Green = Success / Connected / Complete
- Amber = Warning
- Red = Error

Avoid introducing additional brand colours.

## Diagram Style

All diagrams should use:

- White background
- Navy title bar
- Rounded rectangles
- Thin connector arrows
- Flat vector icons
- Consistent spacing
- Minimal text
- 16:9 landscape layout

Avoid:

- Gradients
- Heavy shadows
- Decorative effects
- Invented architecture
- Technologies not used by the project

## Documentation Images

Preferred filenames:

- architecture-diagram.png
- workflow-summary.png
- test-execution-flow.png
- project-overview.png
- instrument-discovery.png
- instrument-library.png
- driver-architecture.png
- engineering-results-flow.png
- platform-support.png

## Screenshot Style

Annotate screenshots using numbered call-outs.

Below each image explain each numbered item in plain engineering language.

## Icons

Icons should be simple outline or flat icons.

Prefer navy.

Use green only to indicate completion or success.

## Typography

- Large navy headings
- Dark grey body text
- Clear spacing
- No coloured body text

## Brand Principles

The visual identity should communicate:

- Engineering
- Reliability
- Traceability
- Simplicity
- Professionalism

Every image should feel like it belongs to the same engineering manual.
