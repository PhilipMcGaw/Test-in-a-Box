# Test in a Box v0.1.0-alpha

This release marks the end of the initial foundation phase.

Test in a Box can configure supported laboratory instruments, build visual
procedures with Blockly, run tests locally, record per-DUT results and
preserve software, configuration and instrument provenance.

## Highlights

- Portable Windows bootstrap requiring no administrator rights.
- Stable and Development updater channels with backups and rollback.
- Instrument Library, discovery and capability-based drivers.
- Bench-tested Aim-TTi and EA PS 2000 B operation.
- Native Seeit USBB relay control on Windows.
- PSU and relay Blockly blocks.
- CSV results, metadata, run manifests and Markdown summaries.

## Alpha status

This is an engineering alpha. Driver validation status must be checked
before relying on a device in a validation programme.
