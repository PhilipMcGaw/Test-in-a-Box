What this is

Test in a Box is a visual, Blockly-based tool for building and running hardware test sequences — define your test equipment, drag blocks together to write a test script without needing to write code, and get live console output plus live console output and per-DUT CSV logs.

Help

A few quick pointers:

  • Test Builder — drag blocks from the toolbox to write a sequence. Use Run, Pause, Step, and Stop to control execution. Save and reload sequences using the bar just below the toolbar.
  • Configure Devices — drag device types from the sidebar onto the canvas to add PSUs, relays, and other instruments. Each device gets a front-panel-style display; use Save & Reconnect to apply changes.
  • Supported Devices — a running list of every device type this app can talk to, and how confident we are in each driver.
  • Full setup and troubleshooting notes live in SETUP_INSTRUCTIONS.md and README.md in the project folder.

Current Bench-Tested Milestone

Blockly-generated procedures have been used to control a physical Thurlby Thandar QL355P power supply. Bench-tested operations include instrument identification, voltage and current setpoints, output enable, output disable, and timed execution.

Engineering examples are included in the repository's examples directory. Automatic instrument-identity recording and Markdown run summaries remain planned Version 0.1 work.

Seeit USB-RELAY08 setup

The Seeit USB-RELAY08 uses a Prolific PL2303 USB-to-serial converter. Windows may require the vendor driver before the board appears as a COM port. Installing the driver normally requires administrator rights.

Driver downloads are available from the Seeit product page.

For shared laboratories and education, an enclosed board with clearly labelled, touch-safe breakout connectors is recommended.
