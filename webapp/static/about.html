What this is

Test in a Box is a visual engineering test-automation platform for building and running repeatable electrical and environmental validation procedures.

Version sources

This page reads the same software identity used by run manifests and Markdown reports:

  • VERSION for the Test in a Box release version;
  • support/BUILD.json for component and layout versions;
  • .update-state.json for managed-update channel, ref, commit, timestamp and archive hash.

An installation that has not yet been managed by Updater V2 is shown as unmanaged.

Help

  • Test Builder creates and runs Blockly procedures.
  • Configure Devices configures and commissions instruments.
  • Supported Devices records driver support and validation status.
  • Setup guidance is under docs/getting-started/ in the project folder.
